# ATLAS DataGob | UPN — Administración de Proyectos de Software

Proyecto académico del **Grupo 5**, VIII ciclo, Universidad Privada del Norte. Implantación simulada de una plataforma agéntica para gestionar demandas de datos, analítica e IA.

**Línea base única (24/10/2026): 6 semanas · S/ 110,000 (est.) · payback 1.5 años (est., hipótesis académica).** La organización piloto, sponsor y cifras del negocio son **ficticios**. No se atribuyen aprobaciones ni firmas reales.
